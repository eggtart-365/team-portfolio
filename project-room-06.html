ROOM 06 팀 웹사이트 프로젝트

01 · 프로젝트 목적

기획 의도 및 목표

방문객이 각 페이지를 둘러보며 하나의 전시실을 관람하는 듯한 팀 웹사이트를 제작하는 것이 목적입니다.

팀의 소개, 팀원, 작업, 기록을 박물관 전시처럼 둘러볼 수 있게 구성했습니다. 여섯 명이 페이지를 나눠 만들고, 공통 디자인 기준에 맞춰 하나로 이어 붙였습니다.

CONCEPT
전시관 소식지 아카이브
FOCUS
역할 분담 · 협업 · 기록
STANDARD
통일된 색과 글꼴
02 · 사용 기술

기술 스택

TECH 01

HTML

시맨틱 태그로 페이지 구획을 나누고, 접근성 속성을 적용해 문서 구조를 명확히 작성했습니다.

TECH 02

CSS

색상과 여백을 한곳에서 관리해 모든 페이지의 모습을 통일하고, 화면 크기에 맞게 배치가 바뀌도록 구성했습니다.

TECH 03

JavaScript

공통 메뉴와 팀원 카드 필터, 티켓 상세 창을 JavaScript로 구현했습니다.

03 · 주요 기능

핵심 기능

기능 01

팀 소개 및 작업

기록·연결·전시 세 가지 콘셉트와 기획에서 완성까지의 과정을 한눈에 보여 줍니다.

INTRO
기능 02

팀원 카드 · 티켓 상세 창

직원증 카드에서 티켓형 상세 창으로 이어지고, QR 코드로 팀원의 GitHub에 바로 접속할 수 있습니다.

MEMBERS
기능 03

활동 기록 및 질문 · 연락 안내

팀 진행 기록을 날짜순으로 살펴보고, 자주 묻는 질문과 연락 기능을 이용할 수 있습니다.

ARCHIVE

01 · 프로젝트 목적

기획 의도 및 목표

방문객이 각 페이지를 둘러보며 하나의 전시실을 관람하는 듯한 팀 웹사이트를 제작하는 것이 목적입니다.

미술관 특집 지면처럼 작품 소개와 맥락을 함께 전하듯, 팀의 방향성과 협업 과정을 차분하게 풀어냈습니다. 통일된 스타일 규격을 기준으로 팀원별 페이지를 구현하고 하나로 합쳤습니다.

CONCEPT
전시관 소식지 아카이브
FOCUS
역할 분담 · 협업 기록
STANDARD
순수 웹 표준 구현
02 · 사용 기술

기술 스택

HTML, CSS, JavaScript 기본기로 구현했습니다.

TECH 01 MARKUP

HTML

시맨틱 태그로 페이지 구획을 나누고, 접근성 속성을 적용해 문서 구조를 명확히 작성했습니다.

TECH 02 STYLING

CSS

:root 변수로 색상과 여백을 통일하고, Grid와 Flexbox로 반응형 레이아웃을 구성했습니다.

TECH 03 SCRIPT

JavaScript

팀원 카드 필터링, 상세 티켓 창과 QR 이미지 표시, FAQ 등 동적 기능을 구현했습니다.

03 · 주요 기능

핵심 기능

페이지 탐색과 정보 확인을 돕는 기능입니다.

기능 01

구분별 필터링 및 팀원 카드 전시

팀장과 팀원 구분에 맞춰 카드를 걸러서 보고, 클릭하면 상세 정보를 확인할 수 있습니다.

GALLERY
기능 02

티켓형 상세 창 및 GitHub QR 코드

상세 창을 티켓 형태로 구성해 담당 정보와 함께 GitHub로 바로 연결되는 QR 코드를 제공합니다.

TICKET QR
기능 03

활동 기록 및 질문·연락 안내

팀 진행 기록을 날짜순으로 살펴보고, 자주 묻는 질문과 연락 기능을 이용할 수 있습니다.

ARCHIVE

최종 결과물과 참여자 담당 내역입니다.

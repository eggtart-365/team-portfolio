ROOM 06은 어떤 팀인가요?
여섯 명이 모여 팀 포트폴리오 웹사이트를 함께 만드는 팀입니다. 팀원 소개는 팀원에 있습니다.
사이트는 무엇으로 만들었나요?
HTML, CSS, JavaScript만 썼습니다. 데이터베이스나 서버 없이 GitHub Pages로 배포하는 정적 웹사이트입니다.
여섯 명이 어떻게 함께 작업하나요?
각자 맡은 기능을 따로 브랜치에서 만들고, Pull Request로 서로 리뷰한 뒤 합칩니다. Git, GitHub, SourceTree를 씁니다.
